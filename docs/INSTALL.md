# Установка и первый запуск

> **DRAZVIO находится в разработке.** Ниже описан тестовый запуск на Windows, а не установка готового публичного релиза.

## Что понадобится

- Windows и серверная сборка **SA-MP 0.3.7-R2** (в тестовом ZIP уже есть `samp-server.exe`).
- **Microsoft Visual C++ 2010 Redistributable (x86)** для старого `streamer.dll` (получайте установщик из официального источника Microsoft).
- Для самостоятельной сборки из исходников: **PowerShell** и **Python 3**.

## Способ 1. Готовая тестовая сборка

1. Откройте [запуски проверки сервера](https://github.com/Zeihos/Drazvio/actions/workflows/filefunctions-compat.yml).
2. Выберите успешный запуск ветки **main** и скачайте артефакт `DRAZVIO-SERVER-TEST`.
3. Распакуйте архив в отдельную папку, например `D:\Games\DRAZVIO`. Не распаковывайте поверх действующего сервера.
4. Создайте `server.cfg` копированием `server.cfg.example`, замените `rcon_password` на длинный случайный пароль и проверьте остальные параметры.
5. При наличии Python и клонированного репозитория проверьте распакованную сборку до запуска: `python tools/drazvio.py check --root "D:\\Games\\DRAZVIO" --deploy` (из корня репозитория). Проверка рассчитана на готовые `.amx`, исходники Pawn для неё не нужны.
6. Запустите `samp-server.exe` из папки сервера.
7. Убедитесь, что в журнале загрузились **FileFunctions**, **sscanf**, **streamer**, а также **11 фильтрскриптов**. Проверьте отсутствие `Run time error 19`.

**Тестовый архив собирается по строгому разрешённому списку файлов и не содержит личный `server.cfg`, чужие аккаунты или прогресс игроков.** Сборка FileFunctions включена только для тестирования совместимости.

## Способ 2. Сборка из исходников

Клонируйте репозиторий или скачайте исходники через **Code → Download ZIP**. Из корня выполните:

```powershell
python tools/drazvio.py check
./tools/build.ps1
```

Компилятор положит `gamemodes_mod05.amx`, `filterscripts_gatesys2.amx`, `filterscripts_reklama.amx` в каталог `build-amx/`. Это **не полная готовая серверная папка**: для работы также нужен совместимый `FileFunctions.dll` и остальные зависимости.

Скрипт настройки создаёт приватный конфиг и отсутствующие начальные INI-файлы. Повторный запуск безопасен: уже существующие `server.cfg` и сохранения **не перезаписываются**:

```powershell
python tools/drazvio.py init
```

Внимание: без совместимой DLL и запуска со всеми зависимостями сервер может завершиться с ошибкой. Проверенная тестовая DLL публикуется **в артефактах GitHub Actions**, а не хранится в исходниках.

## Резервная копия перед обновлением

Полностью **остановите SA-MP** и из корня клонированного репозитория запустите:

```powershell
python tools/backup_server.py --root "D:\\Games\\DRAZVIO" --output "D:\\Backups\\drazvio-before-update.zip"
```

Скрипт сохраняет исходный `server.cfg` и всё содержимое `scriptfiles/` без изменения байтов. Проверяет ZIP после записи, не перезаписывает уже существующий архив, отклоняет ссылки на внешние файлы и не позволяет сохранить архив внутри папки сервера. Папка назначения должна существовать заранее.

**Это конфиденциальный незашифрованный архив**: он может содержать RCON-пароль, аккаунты, IP-адреса и прогресс игроков. Не добавляйте его в Git, GitHub Issues, публичные облака и артефакты CI. Храните вне общедоступных папок с ограниченными правами доступа. Перед заменой файлов сохраните резервную копию отдельно от сервера.

## Безопасность перед запуском в интернет

- Не публикуйте в репозитории `server.cfg`, аккаунты, журналы, IP игроков и резервные копии.
- Если раньше секреты находились в публичной истории Git, **смените их**: `.gitignore` не удаляет историю.
- Перед изменением или обновлением рабочего сервера сохраните `server.cfg` и **всю** папку `scriptfiles`.
- Проверьте регистрацию, сохранение после рестарта, команды администрирования и экономику на тестовом сервере.
- Настройте резервное копирование и ограничьте доступ к серверу до завершения проверки.

## Частые проблемы

| Проблема | На что обратить внимание |
| --- | --- |
| `Loading plugin: FileFunctions — Failed` | Устаревшая DLL требовала отладочную `MSVCR100D.dll`; используйте тестовую совместимую сборку из CI |
| `Loading plugin: streamer — Failed` | Проверьте установленный **VC++ 2010 Redistributable x86** |
| `Run time error 19` | Не загрузилась DLL или отсутствует используемая native-функция |
| Сервер закрывается при запуске | Проверьте наличие `scriptfiles/data/*.ini` и полный `server_log.txt` |
