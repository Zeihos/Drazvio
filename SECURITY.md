# Безопасность DRAZVIO

Для проекта важны защита аккаунтов, права администраторов и надёжное сохранение игровых данных.

## Если нашли уязвимость

**Не публикуйте** в открытом Issue действующие пароли, RCON-ключи, IP игроков, файлы аккаунтов, уязвимости с готовыми инструкциями злоупотребления и другие конфиденциальные данные.

Проверьте, доступна ли опция **Report a vulnerability** на вкладке [Security](https://github.com/Zeihos/Drazvio/security). Если приватное сообщение через GitHub недоступно, обратитесь к владельцу проекта через [профиль Zeihos](https://github.com/Zeihos), не раскрывая технические детали в публичных комментариях.

Для обычных ошибок используйте [Issues](https://github.com/Zeihos/Drazvio/issues/new/choose).

## Публикация конфигураций

- Не коммитьте рабочий `server.cfg` и файлы из каталогов с аккаунтами.
- Не используйте общие или слабые RCON-пароли.
- Если пароль когда-либо появлялся в Git, **замените его**. Удаление файла не удаляет секрет из истории коммитов.
- Делайте резервные копии до обновления DLL, AMX или структуры `scriptfiles`.

**Статус:** проект ещё проходит тестирование, а экспериментальная DLL не объявлена полноценным релизом.
