# Участие в разработке

Спасибо за интерес к **DRAZVIO**. Основной язык общения по вопросам проекта — **русский**.

## Как сообщить об ошибке

1. Проверьте существующие [Issues](https://github.com/Zeihos/Drazvio/issues).
2. Создайте сообщение через [шаблон ошибки](https://github.com/Zeihos/Drazvio/issues/new/choose).
3. Укажите версию мода, действие перед ошибкой и **обезличенный** фрагмент лога.
4. Если проблема касается аккаунтов или прав доступа, **не публикуйте личные данные и пароли**.

## Как предложить изменения

1. Создайте отдельную ветку от актуальной `main`.
2. Вносите небольшие, связанные между собой изменения; не смешивайте игровую механику с реорганизацией проекта.
3. Выполните `python tools/drazvio.py check`, `python tools/repository_audit.py` и `./tools/build.ps1` на Windows.
4. Откройте Pull Request и подробно опишите проверку и потенциальный риск для сохранений.

### Не добавляйте в Pull Request

- Реальные `server.cfg`, токены, RCON-пароли, аккаунты игроков и IP-адреса.
- Готовые ZIP предыдущих версий, старые AMX, журналы и резервные копии.
- Сторонние изображения или код без прав на использование и указания источника.

## Лицензирование

Публичная доступность исходников сама по себе **не означает** разрешение на свободное копирование, коммерческое использование или распространение. Если вам требуется такое разрешение, уточните условия у владельца репозитория.
